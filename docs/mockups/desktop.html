AI와 일하는 방식

구현 전에 통과 기준부터

  1. 1 · 문서

    기대 동작과 성공 사례

    아는 것부터 docs/에 적고, AI의 질문에 답하며 기대 동작과 성공 사례를 정리합니다.

    요구사항이 빠졌으면 → 인터뷰 후 문서에 반영

  2. 2 · 개발 계획 · Eval

    기능별 통과 기준

    기능의 우선순위를 정하고, 확인할 동작과 통과 조건을 구현 전에 적습니다.

    기준이 모호하면 → AI가 다시 질문, 답을 계획에 반영

  3. 3 · 기능 개발

    같은 기준으로 검증

    기능마다 하네스를 정해 구현하고, 계획에 적어 둔 기준으로 테스트합니다.

    기준에 못 미치면 → 수정 후 같은 기준으로 재테스트
